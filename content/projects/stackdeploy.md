StackDeploy is our internal deployment platform that makes shipping containerized applications to production effortless.

## Overview

Zero configuration required — point StackDeploy at a repo and it handles building, testing, and deploying your application with full observability built in.

## Key Features

- Automatic Docker image builds
- Multi-region deployment support
- Built-in metrics and tracing
- GitOps-first workflow
